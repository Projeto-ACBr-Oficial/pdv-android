Meeting · Fase 1–3

Migração bem-sucedida dos módulos fiscais PDV ACBr → C++

Pesquisa profunda no monorepo ACBr, port comportamental do núcleo tributário, demo NFC-e e testes com cobertura ≥ 90%.

1. O que é o ACBr no contexto PDV Android?

  • Framework Pascal de automação comercial brasileira
  • ACBrLibNFe Android: AAR + JNA + .so nativo
  • Fluxo PDV: validar → tributar → chave → XML NFC-e → assinar → SEFAZ
  • C++ existente no ACBr: apenas loader da DLL, não reescrita

2. Descobertas da pesquisa

  • ~2.100 units .pas; só ACBrDFe ~1.074
  • OpenSSL 1.1.1w e LibXML2 2.9.10 no tree Android (legados)
  • Demos Pascal/Android não executáveis neste host (sem FPC/SDK + .so)
  • Fixtures de ACBrValidadorTest serviram de ouro para o port

3. Estratégia de migração

  • Não reescrever o monorepo inteiro de uma vez
  • Portar o tax core PDV com paridade de algoritmos
  • C++17 zero-deps runtime + C API estilo ACBrLib
  • Próxima onda: OpenSSL 3.x (Assinar) + libcurl (SEFAZ)

7. Bibliotecas — compatibilidade
